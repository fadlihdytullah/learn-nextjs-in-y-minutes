# Learn Next.js in Y Minutes

Short lessons for Next.js 16 (App Router, Cache Components).
Each lesson explains an idea briefly, runs a live demo on the page, and shows the code behind it.

```bash
npm install
npm run dev   # http://localhost:3000
```

Lessons live in `app/NN-topic/`: `page.tsx` holds the explanation, and each small colocated file is one demo.
Shared helpers are in `app/_lib/`. To add a lesson: create the route folder, then register it in `app/_lib/lessons.ts`.

Illustrations: prompts are in `IMAGE.md`. Save generated images to `public/images/`.
