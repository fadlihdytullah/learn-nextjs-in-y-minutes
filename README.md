# Learn Next.js in Y Minutes

Runnable, commented lessons for Next.js 16 (App Router, Cache Components).
Each lesson is a real route: a live demo on top, the source that renders it below.

```bash
npm install
npm run dev   # http://localhost:3000
```

Lessons live in `app/NN-topic/`. Shared helpers are in `app/_lib/`.
To add one: create the route folder, then register it in `app/_lib/lessons.ts`.
